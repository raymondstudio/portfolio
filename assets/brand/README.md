# Raymond Studio mark

The primary symbol is a geometric R with a deliberate 45-degree cut and a compact terminal block. The cut gives the mark a recognizable silhouette at small sizes, while the green terminal creates a repeatable motion cue for the portfolio's design/build/scale language.

- Primary: `raymond-studio-mark.svg` on `#03040c`
- Transparent: `raymond-studio-mark-transparent.svg`
- Green: `#39ff14`
- Near-black: `#03040c`

The mark is vector-native and can be exported to PNG, WebP, or app-icon sizes without redraw.
